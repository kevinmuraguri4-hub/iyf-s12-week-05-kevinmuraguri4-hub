## Project Description
This repository contains practice exercises for Lessons 9–10 and an interactive To-Do List mini-project. It demonstrates selecting and changing DOM elements, creating and removing elements, handling browser events, event delegation, and validating form input.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Add, complete, edit, delete, and filter tasks
- Clear completed tasks and see the number of active tasks
- Responsive layout and dark mode toggle
- DOM selection, traversal, content, attribute, and style practice
- Event listeners, keyboard events, bubbling, and delegation examples
- Five daily DOM challenges in `daily-challenges/`

## How to Run
1. Open the repository on GitHub and choose **Code → Download ZIP**.
2. Extract the ZIP file.
3. Open `index.html` in Chrome or another modern browser.
4. Open `dom-practice.html` to explore the Lesson 9–10 examples.
5. Open any HTML file in `daily-challenges/` to try a daily challenge.

No installation or API key is required.
